# 留言规则

前端和 Cloudflare Worker 共享 `src/moderation.js`，不依赖第三方在线审核服务，也不会为了本地留言请求云端。对新留言的昵称和正文同时检查；历史留言不批量删除。

## 屏蔽词

`src/moderation-words.js` 从 LDNOOBW GitHub 原仓库的 `en` 与 `zh` 文件离线生成，分别 403 与 319 条。来源和 CC BY 4.0 许可见 `licenses/THIRD_PARTY_NOTICES.md`。

英文忽略大小写，按单词边界匹配，避免 `ass` 误伤 `class`、`assignment`。中文多字词按包含匹配，单字词仅匹配整条内容，避免“性”“奶”等单字误伤正常表达。校验前做 NFKC 和常见零宽字符清理。词表并非语义审核，可能误判或漏判；可以在保留许可的前提下按社区实际情况调整。

## 网址和邮箱

网站域名仅允许最后一级为 `.cn`、`.com`、`.us`、`.tv`，含合法子域名。检查显式 HTTP(S) URL、协议相对 URL、`www.` 和裸域名。IP 地址链接和其他协议不接受；`safe.com.evil.org` 或 `safe.com@evil.org` 不能借允许的文字绕过。允许的网址路径、查询参数里出现其他域名字样，不按新的主机名判断。纯文本代码始终以 `textContent` 显示，不生成可执行 HTML。

符合邮箱语法的 `local@domain` 在发送前转换为 `local#domain`；邮箱自身的域名不按网站域名规则拒绝。普通 `@昵称`、无域名的 `foo@bar`、URL 用户信息中的 `@` 不当成邮箱。识别只做语法检查，不联网验证邮箱是否存在。正文和昵称入库前都再由服务端检查、脱敏。该替换只是减少直接展示邮箱，不是加密或匿名保证。

不把运营者的私人收件地址、邮箱密钥、私有邮件内容或收件箱配置写入此公开仓库；不复用公开留言数据库存储私有邮件。
